# PRO MAX OS 2.6.3 — نظام الإدارة المتكامل

نظام إدارة موارد المؤسسات (ERP) متعدد المنشآت، يشمل المحاسبة، المخزون، الإنتاج، الموارد البشرية، الفوترة الإلكترونية (عُمان/السعودية)، إيداع القوائم المالية (الكويت)، الذكاء الاصطناعي، ومصنع الأكواب.

---

## متطلبات التشغيل
- Windows 10/11 — 64-bit
- WebView2 Runtime (مثبت مسبقاً على معظم الأنظمة الحديثة)
- **متطلبات إضافية (اختيارية):**
  - مسح OCR محلي (بدون إنترنت): Tesseract 5 مع لغتي `ara` و `eng` مثبت في `C:\Program Files\Tesseract-OCR`
  - خدمات الذكاء الاصطناعي: مفاتيح OpenAI / Anthropic / Groq / Gemini
  - تشغيل خادم API البعيد: يُفضل إضافة قواعد جدار الحماية لمنفذ الخادم

## التثبيت
1. شغّل `PRO MAX OS_2.6.3_x64-setup.exe` (أو MSI للبيئات المؤسسية).
2. يتثبت البرنامج في `%LOCALAPPDATA%\PRO MAX OS` مع قاعدة بيانات محلية.
3. ضع ملف الترخيص `.promax_os_license` بجانب الملف التنفيذي إن لم يكن مرفقاً.

## النسخة المحمولة (Portable)
- انسخ `promax-os.exe` إلى أي مجلد وقم بتشغيله مباشرة.
- قاعدة البيانات تُنشأ تلقائياً في `%LOCALAPPDATA%\com.promaxos.app\promax.db`.

## التحديث التلقائي

من الإعدادات ← «التحديثات» يمكن التحقق من وجود إصدار أحدث وتثبيته وإعادة تشغيل التطبيق تلقائياً.

- خادم التحديثات: `https://releases.promaxos.com/update/{{target}}/{{bundle_type}}/{{current_version}}`
- التوقيع: تُوقّع المثبتات بمفتاح `rsign` وتُتحقق من التطبيق المثبت قبل التثبيت.
- ملفات التحديث (`updates/`) جاهزة للنشر على خادم التحديثات، مع توقيع لكل نوع مثبت (NSIS / MSI).

> ملاحظة: التحقق من التحديث يتطلب الوصول إلى خادم `releases.promaxos.com`. في حالة عدم توفر الشبكة يعرض التطبيق رسالة «تعذر التحقق».

## إصلاحات 2.6.3

- **واجهة التحديثات:** صفحة الإعدادات تعرض بطاقة «التحديثات» للتحقق والتحميل والتثبيت وإعادة التشغيل (`@tauri-apps/plugin-updater` + `tauri-plugin-process`).
- **المثبتات الموقّعة:** تُنشأ ملفات `.sig` تلقائياً أثناء البناء (`createUpdaterArtifacts`)، مع تدوير المفتاح العام في إعدادات التحديث ليطابق المفتاح الجديد.
- **endpoint محسّن:** أُضيف متغير `{{bundle_type}}` إلى عنوان خادم التحديثات ليميز بين حزم NSIS و MSI.
- **أداة تحقق:** `verify_updater_sig` (مثال Rust في `src-tauri/examples`) يتحقق من صحة التوقيع ضد الملف والمفتاح العام — نفس مسار التحقق الذي يستخدمه العميل.

## إصلاحات 2.6.2

- **تصحيح نسخ الفاتورة (`duplicate_invoice`):** إصلاح خطأ في إدراج القيم كان يكتب ملاحظة النسخة في حقل الحالة بدلاً من الملاحظات؛ النسخ الآن ذري ويحافظ على الإعدادات (`vat_enabled`، `is_commercial`، `payment_type`، `customs_price_milli`).
- **حساب عكس إشعار الخصم:** يُقيد الآن نفس الحساب الذي حُدّد في الفاتورة الأصلية (1100 نقدي / 1101 شيك / 1200 ذمم) بدلاً من حساب الذمم دائماً.
- **فرض الحد الائتماني عند الترحيل:** ترحيل فاتورة آجلة تتجاوز الحد الائتماني للعميل يُرفض (الحد `0` أو أقل يعني غير محدود).
- **دقة التقارير:** تقارير أعمار العملاء، وضريبة القيمة المضافة، وملخص المالك، وهامش المخزون، والفواتير غير المسددة تُحتسب الآن بعد خصم إشعارات الخصم وباستخدام صافي القيم.
- **ترحيلات منشآت جديدة:** ترقيات قاعدة البيانات 15/21/27 تستخدم `ADD COLUMN IF NOT EXISTS` فلا تتوقف في منتصف العملية على التثبيتات الجديدة؛ مزامنة `schema.sql` (سعر الجمرك + جدولي الكوتيشنات).
- **التحقق من المدخلات:** رفض البنود الفارغة والكميات غير الموجبة والأسعار السالبة على الفواتير التجارية والكوتيشنات والفواتير والمشتريات ومدفوعات الموردين والمصروفات ومدفوعات العملاء والمقايضة، مع استرجاع كامل للمستند عند الفشل.
- **أمان الأوامر:** تعقيم كل أوامر الطباعة/المسح عبر `ps_quote`؛ تنسيق كمية الفاتورة الإلكترونية بثلاث خانات عشرية.
- **الواجهة:** إزالة القيمة الافتراضية لعدد الكراتين في الفواتير التجارية والكوتيشنات، حماية لوحة المصنع من استجابات قديمة، عنوان الطباعة التجارية يوضح إجمالي الأكواب، تسميات وصول لأزرار المصنع.
- **اختبارات:** إضافة 7 اختبارات انحدار (143 اختباراً ناجحاً) تغطي الرفض والصلاحيات وتدفق الفاتورة التجارية الكامل (إنشاء → ترحيل → قيد → مخزون).

## التحقق من المجاميع (SHA-256)
PowerShell:
```powershell
Get-FileHash "PRO MAX OS_2.6.3_x64-setup.exe" -Algorithm SHA256
```
قارن الناتج مع ما هو موجود في `SHA256SUMS.txt`.

## التحقق من التوقيعات
```powershell
cd src-tauri
cargo run --example verify_updater_sig -- `
  "..\release\PRO MAX OS 2.6.3\PRO MAX OS_2.6.3_x64-setup.exe" `
  "..\release\PRO MAX OS 2.6.3\PRO MAX OS_2.6.3_x64-setup.exe.sig" `

# الناتج المتوقع: SIG_VERIFY_OK
```
