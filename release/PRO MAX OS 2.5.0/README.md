# PRO MAX OS 2.5.0 — نظام الإدارة المتكامل

نظام إدارة موارد المؤسسات (ERP) متعدد المنشآت، يشمل المحاسبة، المخزون، الإنتاج، الموارد البشرية، الفوترة الإلكترونية (عُمان/السعودية)، إيداع القوائم المالية (الكويت)، والذكاء الاصطناعي.

---

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `PRO MAX OS_2.5.0_x64-setup.exe` | برنامج التثبيت (NSIS) — Windows 64-bit |
| `PRO MAX OS_2.5.0_x64_en-US.msi` | حزمة التثبيت المؤسسية (MSI/WiX) — Windows 64-bit |
| `.promax_os_license` | ملف الترخيص (Enterprise — ساري حتى 2036-12-31) |
| `promax.secrets.template.json` | قالب مفاتيح التشفير (استبدل القيم لتخصيص التثبيت) |
| `promax-os.exe` | النسخة المحمولة (Portable) — بدون تثبيت |
| `promax-api.exe` | خادم واجهة API (اختياري — للتكامل البعيد) |
| `promax-mcp.exe` | خادم MCP للذكاء الاصطناعي (اختياري) |
| `SHA256SUMS.txt` | قائمة المجاميع للتحقق من سلامة الملفات |

## متطلبات التشغيل
- Windows 10/11 — 64-bit
- WebView2 Runtime (مثبت مسبقاً على معظم الأنظمة الحديثة)
- **متطلبات إضافية (اختيارية):**
  - مسح OCR محلي (بدون إنترنت): Tesseract 5 مع لغتي `ara` و `eng` مثبت في `C:\Program Files\Tesseract-OCR`
  - خدمات الذكاء الاصطناعي: مفاتيح OpenAI / Anthropic / Groq / Gemini
  - تشغيل خادم API البعيد: يُفضل إضافة قواعد جدار الحماية لمنفذ الخادم

---

## التثبيت
1. شغّل `PRO MAX OS_2.5.0_x64-setup.exe` (أو MSI للبيئات المؤسسية).
2. يتثبت البرنامج في `%LOCALAPPDATA%\PRO MAX OS` مع قاعدة بيانات محلية.
3. ضع ملف الترخيص `.promax_os_license` بجانب الملف التنفيذي إن لم يكن مرفقاً.

## النسخة المحمولة (Portable)
- انسخ `promax-os.exe` إلى أي مجلد وقم بتشغيله مباشرة.
- قاعدة البيانات تُنشأ تلقائياً في `%LOCALAPPDATA%\com.promaxos.app\promax.db`.

## الجديد في 2.5.0
- **أساس الفوترة الإلكترونية العمانية (فاوترة):**
  - بناء مستند PINT-OM (CrossIndustryInvoice) من فاتورة مرحّلة مع رمز QR بتنسيق TLV (البائع، الرقم الضريبي، التوقيت، الإجمالي، الضريبة) وتحليل تفصيلي لكل خانة.
  - فحص جاهزية المنشأة (اسم الشركة، الرقم الضريبي، السجل التجاري، عملة الريال، ضريبة 5%) مع درجة جاهزية مباشرة من صفحة الفوترة الإلكترونية.
  - معمارية موصل (Connector) للربط مع مزود الخدمة المعتمد ASP/OTA (بيئة تطوير للاختبار + بيئة إنتاج عبر HTTPS) — أساس فني لتوافق القرار 189/2026 (الإلزام أبريل/أكتوبر 2027) مع توضيح أن التفعيل النهائي يتطلب اعتماد جهة الإيرادات.
  - إرسال تلقائي للصف عند ترحيل الفاتورة حسب إعداد "الإرسال عند الترحيل".
- **العهد والصرف النثري:** صفحة جديدة بإنشاء صناديق العهد (أمين، حد الصرف)، تسجيل المصاريف والسلف، التحويل بين الصناديق، وكشف حساب مفلتر بالتاريخ مع رصيد جارٍ لكل صندوق.
- **حذف آمن من صفحات التفاصيل:** حذف (ناعم) للعملاء والموردين والمنتجات والموظفين مع نافذة تأكيد، مع الحفاظ على السجل المحاسبي.
- **تعديل ملاحظات الفاتورة** من صفحة الفاتورة نفسها (تظهر في الطباعة).
