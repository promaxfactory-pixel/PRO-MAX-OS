# PRO MAX OS 2.2.0 — حزمة التوزيع الكاملة

نظام إدارة متكامل (ERP + نقاط بيع) للمصانع والشركات الصغيرة والمتوسطة في الكويت والخليج.
واجهة عربية/إنجليزية، يعمل دون إنترنت، ورخصة دائمة تملك بياناتك.

---

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `PRO MAX OS_2.2.0_x64-setup.exe` | المثبّت الموصى به (NSIS) — 64-bit |
| `PRO MAX OS_2.2.0_x64_en-US.msi` | المثبّت البديل (MSI/WiX) — 64-bit |
| `.promax_os_license` | ملف الترخيص (Enterprise، صالح حتى 2036-12-31) |
| `promax.secrets.template.json` | قالب إعدادات الأسرار (لا يحتوي أي سر حقيقي) |
| `SHA256SUMS.txt` | بصمات التحقق من سلامة الملفات |

---

## متطلبات النظام
- Windows 10/11 — 64-bit
- WebView2 Runtime (يُثبَّت تلقائيًا مع المثبّت عند الحاجة)
- **وحدات إضافية (اختيارية):**
  - وحدة OCR (مسح الفواتير): Tesseract 5 مع حزمتي `ara` و`eng` — ثُبِّت مسبقًا على هذا الجهاز في `C:\Program Files\Tesseract-OCR`
  - وحدة الذكاء الاصطناعي: مفتاح OpenAI / Anthropic / Groq / Gemini
  - الفوترة الإلكترونية: بيانات بوابة هيئة الزكاة والضريبة (وضع تجريبي/إنتاجي)

---

## التثبيت
1. شغّل `PRO MAX OS_2.2.0_x64-setup.exe` (أو MSI).
2. أكمل المعالج — سيُثبَّت في `%LOCALAPPDATA%\PRO MAX OS`.
3. الترخيص وملف الأسرار يُنشآن تلقائيًا بجانب البرنامج عند أول تشغيل.

## إعداد وحدة الذكاء الاصطناعي
المفاتيح تُحفظ مشفّرة داخل قاعدة البيانات (لا تُكتب في ملفات). أضفها من شاشة إعدادات AI:
- OpenAI: `https://api.openai.com/v1` — نموذج `gpt-4o`
- Anthropic: `https://api.anthropic.com/v1` — نموذج `claude-3-opus`

## التحقق من السلامة (SHA-256)
PowerShell:
```powershell
Get-FileHash "PRO MAX OS_2.2.0_x64-setup.exe" -Algorithm SHA256
```
قارن الناتج بالقيمة في `SHA256SUMS.txt`.
