# PRO MAX OS 2.4.1 — نظام الإدارة المتكامل

نظام إدارة موارد المؤسسات (ERP) متعدد المنشآت، يشمل المحاسبة، المخزون، الإنتاج، الموارد البشرية، الفوترة الإلكترونية (عُمان/السعودية)، إيداع القوائم المالية (الكويت)، والذكاء الاصطناعي.

---

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `PRO MAX OS_2.4.1_x64-setup.exe` | برنامج التثبيت (NSIS) — Windows 64-bit |
| `PRO MAX OS_2.4.1_x64_en-US.msi` | حزمة التثبيت المؤسسية (MSI/WiX) — Windows 64-bit |
| `.promax_os_license` | ملف الترخيص (Enterprise — ساري حتى 2036-12-31) |
| `promax.secrets.template.json` | قالب مفاتيح التشفير (استبدل القيم لتخصيص التثبيت) |

| `promax-api.exe` | خادم واجهة API (اختياري — للتكامل البعيد) |
| `promax-mcp.exe` | خادم MCP للذكاء الاصطناعي (اختياري) |
| `SHA256SUMS.txt` | قائمة المجاميع للتحقق من سلامة الملفات |

## متطلبات التشغيل
- Windows 10/11 — 64-bit
- WebView2 Runtime (مثبت مسبقاً على معظم الأنظمة الحديثة)
- **متطلبات إضافية (اختيارية):**
  - مسح OCR محلي (بدون إنترنت): Tesseract 5 مع لغتي `ara` و `eng` مثبت في `C:\Program Files\Tesseract-OCR`
  - خدمات الذكاء الاصطناعي: مفاتيح OpenAI / Anthropic / Groq / Gemini
  - تشغيل خادم API البعيد: يُفضل إضافة قواعد جدار الحماية لمنفذ الخادم

## التثبيت
1. شغّل `PRO MAX OS_2.4.1_x64-setup.exe` (أو MSI للبيئات المؤسسية).
2. يتثبت البرنامج في `%LOCALAPPDATA%\PRO MAX OS` مع قاعدة بيانات محلية.
3. ضع ملف الترخيص `.promax_os_license` بجانب الملف التنفيذي إن لم يكن مرفقاً.

## النسخة المحمولة (Portable)
- انسخ `promax-os.exe` إلى أي مجلد وقم بتشغيله مباشرة.
- قاعدة البيانات تُنشأ تلقائياً في `%LOCALAPPDATA%\com.promaxos.app\promax.db`.

## الجديد في 2.4.1
- **الإشعارات الدائنة (Credit Notes) — دورة كاملة:**
  - إنشاء إشعار دائن على أي فاتورة مرحّلة من صفحة الفاتورة نفسها، مع تحديد كمية الإرجاع لكل منتج (تُحتسب تلقائياً الكمية المتبقية بعد الإشعارات السابقة) والسبب.
  - الأمان المحاسبي: السعر والضريبة يُؤخذان من بنود الفاتورة الأصلية فقط، ويُمنع تجاوز الكميات المرجعة؛ تُعاد الكميات للمخزون مع حركات مخزون، وتُرحَّل قيود عكسية متوازنة (إيراد/ضريبة/مدينون، ومخزون/تكلفة البضاعة)، وينخفض رصيد العميل تلقائياً للفواتير الآجلة.
  - ترقيم تلقائي `CN-YYYY-####`، ورقم مرجعي للفاتورة الأصلية، وسجل من صفحة **الإشعارات الدائنة** الجديدة مع طباعة مباشرة.
  - طباعة إشعار بمستند إشعار دائن كامل (بيانات الشركة، البنود، الإجماليات، التوقيع).
- **سند صرف للموردين:** بعد تسجيل دفعة لمورد تظهر شاشة نجاح مع زر "طباعة سند صرف" (وكانت طباعة إيصال العملاء متاحة من 2.4.0).
- موثوقية الأعمال المالية: كل العمليات تُسجل في سجل التدقيق (Audit Log) مع منع الإشعار على فواتير غير مرحّلة.
