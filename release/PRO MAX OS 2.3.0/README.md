# PRO MAX OS 2.3.0 — نظام الإدارة المتكامل

نظام إدارة موارد المؤسسات (ERP) متعدد المنشآت، يشمل المحاسبة، المخزون، الإنتاج، الموارد البشرية، الفوترة الإلكترونية (عُمان/السعودية)، إيداع القوائم المالية (الكويت)، والذكاء الاصطناعي.

---

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `PRO MAX OS_2.3.0_x64-setup.exe` | برنامج التثبيت (NSIS) — Windows 64-bit |
| `PRO MAX OS_2.3.0_x64_en-US.msi` | حزمة التثبيت المؤسسية (MSI/WiX) — Windows 64-bit |
| `.promax_os_license` | ملف الترخيص (Enterprise — ساري حتى 2036-12-31) |
| `promax.secrets.template.json` | قالب مفاتيح التشفير (استبدل القيم لتخصيص التثبيت) |
| `promax-os.exe` | النسخة المحمولة (Portable) — بدون تثبيت |
| `promax-api.exe` | خادم واجهة API (اختياري — للتكامل البعيد) |
| `promax-mcp.exe` | خادم MCP للذكاء الاصطناعي (اختياري) |
| `SHA256SUMS.txt` | قائمة المجاميع للتحقق من سلامة الملفات |

## متطلبات التشغيل
- Windows 10/11 — 64-bit
- WebView2 Runtime (مثبت مسبقاً على معظم الأنظمة الحديثة)
- **متطلبات إضافية (اختيارية):**
  - مسح OCR محلي (بدون إنترنت): Tesseract 5 مع لغتي `ara` و `eng` مثبت في `C:\Program Files\Tesseract-OCR`
  - خدمات الذكاء الاصطناعي: مفاتيح OpenAI / Anthropic / Groq / Gemini
  - تشغيل خادم API البعيد: يُفضل إضافة قواعد جدار الحماية لمنفذ الخادم

## التثبيت
1. شغّل `PRO MAX OS_2.3.0_x64-setup.exe` (أو MSI للبيئات المؤسسية).
2. يتثبت البرنامج في `%LOCALAPPDATA%\PRO MAX OS` مع قاعدة بيانات محلية.
3. ضع ملف الترخيص `.promax_os_license` بجانب الملف التنفيذي إن لم يكن مرفقاً.

## النسخة المحمولة (Portable)
- انسخ `promax-os.exe` إلى أي مجلد وقم بتشغيله مباشرة.
- قاعدة البيانات تُنشأ تلقائياً في `%LOCALAPPDATA%\com.promaxos.app\promax.db`.

## الجديد في 2.3.0
- **الفوترة الإلكترونية السعودية — المرحلة الثانية (ZATCA)**: توليد فواتير UBL 2.1، توقيع ECDSA (secp256k1)، رمز QR بتقنية 9 حقول، التسجيل الآلي لشهادة CSID (امتثال + إنتاج)، الإجازة الآلية (Clearance) والإبلاغ (Reporting)، والتحقق من متطلبات ZATCA (BR-KSA).
- **قيد — إيداع القوائم المالية (XBRL)**: توليد نماذج XBRL متوافقة مع تصنيف وزارة التجارة والصناعة الكويتية (moici-ifrs) بالدينار الكويتي، مع تحقق من التسوية. إلزامي اعتباراً من 2027-01-01.
- **الفروع المتعددة والمزامنة دون اتصال**: إدارة فروع متعددة (رئيسي/فرع)، وقائمة مزامنة للمعاملات التي تتم أثناء انقطاع الاتصال مع إمكانية الإعادة والمزامنة.
- تحسينات في مخطط قاعدة البيانات (الإصدار 34) واختبارات شاملة.

## التحقق من المجاميع (SHA-256)

```powershell
Get-FileHash "PRO MAX OS_2.3.0_x64-setup.exe" -Algorithm SHA256
```
قارن الناتج مع ما هو موجود في `SHA256SUMS.txt`.
